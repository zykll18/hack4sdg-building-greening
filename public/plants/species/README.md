# Authored species concept GLBs

Thirty small GLBs generated by the Building Greening project, with the library expanded on 17 October 2026. Source: `src/adapters/species-models.js`; generator: `scripts/generate-species-models.mjs`. No third-party geometry, textures or catalog photographs are included. Reuse follows the project code licensing policy. Each self-contained GLB uses ordinary meshes and includes species ID and concept status in root extras.

These are illustrative clumps/vine segments. Leaf outlines, colour, size, flower/bract display and density are authored approximations, not professionally verified botanical specimens, mature dimensions or growth/season forecasts. Building facade placement additionally generates vines against actual clipped surfaces. The downloadable unit is not an entire facade installation or a BIM construction assembly.

`manifest.json` records bytes and SHA-256. Re-run the generator after geometry changes; it updates the GLBs, manifest and catalog visualModel hashes together. Botanical references and licensed photos stay separate in the catalog and `../library/`.
