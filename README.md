# Building Greening Decision Support

An IFC-based presentation workspace for building professionals to compare the original building with one adopted greening proposal across roofs, facades, balconies/terraces and ground areas. AI recommends locations, plants and coverage; users choose what to adopt and adjust. Developers or building owners review the resulting before/after comparison.

## Presentation flow

Calculator opens a green project-background note on the left after loading a new model. Confirm the city, building use and new-build/retrofit stage (unknown is allowed); optional HKD budget, irrigation and maintenance stay folded. Confirmation pins the summary beside the building; edit it any time. AI requests include this confirmed context, and an attempted request waits for confirmation. Project saving/backup retain it; a different imported model starts afresh. Non-Hong-Kong cities do not automatically inherit the Hong Kong carbon reference model.

1. Run `npm ci` and `npm run dev`, then open `http://127.0.0.1:5173/` (Node >=22.12.0). The glass EcoMetroLink Dashboard opens first, with persistent top/bottom navigation. Calculator opens the live IFC workspace and initially loads the KIT office example. Dashboard sample tiles open other architectural models directly. Project retains all six examples and local IFC import.
2. Location screening runs internally after loading. **Click a suitable building component** to inspect it, then choose **Add to plan** to add planting at **50% coverage**. Remove it from its location card. Earlier planting remains visible. Pitched and curved roofs are available as conditional concept candidates; planting follows original upward roof faces. Roof identity and usable-geometry checks remain. These are concept screening assumptions, not engineering approval.
3. Open **Inspect** to see every selected location in its own expanded card with plant photo, species, coverage and planted area. Changes update the building and the current before/after comparison immediately. Ask by text or microphone for validated location/plant suggestions; Adopting a recommendation applies its validated species and suggested coverage, preserving earlier planting. **Finished** only closes Inspect. No separate Preview or acknowledgement step is required. Original IFC identities and atomic surface validation remain unchanged.
4. For **Ground / courtyard**, choose **+ Ground area**, set rectangle dimensions and offsets, review the resulting surface and choose **Add planting**. The rectangle must stay outside the conservative building bounding footprint. Default coverage is 50%. It is user-defined design geometry, not an IFC site/ownership boundary; available land, ground level and utilities remain site checks.
5. Open **Compare** separately to view **Original building / Before** versus **Current planting / After**. The current proposal contains only adopted recommendations and your edits, not two preset alternatives. Before hides proposed plants; After restores the same proposal without changing inputs. Compare shows added planting area, incremental installation/maintenance cost, supplied baseline/after electricity and sourced net carbon change. Original whole-building carbon remains unknown. These are illustrative 3D systems; vegetation counts do not change calculated coverage or impacts.
6. In **Project**, edit the comparison period/optional budget or load another model. Replacement clears old regions and overlays. Save/Restore retain the last complete local project; opening Calculator restores it automatically. Export/Import complete project transfers original model bytes, planting, camera/view, chat, conditions and evidence inputs. Comparison reports alone cannot restore a model.
7. Download the HTML comparison report and JSON handoff. They retain current model/IFC identities, areas, systems, factors, checks and results for team integration.

In **View → Plant appearance**, switch between **Textured planting** and **Simplified planting**. Bundled Fern 02 and Shrub 03 add leaf detail to Landscape roofs/courtyards and fern-filled terrace planters. Source credits and licenses are in `public/plants/README.md`; facade vegetation and trees still use simplified geometry.

**Flora is the independent plant-library page; Inspect holds site conditions and recommendations.** Ask `Which roof plants?` or `屋顶植物，150毫米，少浇水，4月`, then review the visible site conditions and source-backed candidate cards. The library stores twelve reviewed Hong Kong species, screens location/depth/water, and uses ornamental months only as a secondary preference. Unknowns stay conditional. Download the shortlist for team integration; Use at selected location assigns the species concept model. Density only changes decoration; explicit coverage updates the current planted area and incremental cost estimate. Reference roof carbon uses published sources and explicit scenario assumptions; project correction needs separately sourced evidence. Sources, data ownership and the bounded AI interface are in [PLANT_LIBRARY.md](PLANT_LIBRARY.md).

**Voice interaction stays in Inspect.** Use the microphone beside the question field, choose Cantonese/Mandarin/English in **Voice language**, and review/edit the transcript. Choose **Ask** (or Enter) to request suggestions. The response alone does not add plants; choosing a suggested location or accepting recommendations adds plants immediately. Microphone access and language support depend on the browser; speech audio may be processed by its speech service. There is no separate Assist panel. AI service configuration and access policy are described below.

A/B/C/D presentation responsibilities and browser acceptance are in [TEAM_TASKS.md](TEAM_TASKS.md); implementation and provenance boundaries are in [ARCHITECTURE.md](ARCHITECTURE.md).

## Verification

`npm test` runs deterministic calculation, identity, whole-set confirmation without partial mutation, four-region aggregation, edge clipping, continuous visual coverage area, compatibility screening, seeded vegetation sampling, hole/edge clearance, bounded density and four-type planting coverage checks. `npm run build` produces the browser build. `node scripts/check-greening.mjs` checks original KIT office candidate screening, then separately exercises synthetic four-region geometry extraction, coverage and plan calculation without claiming browser or spatial suitability validation. `npm run test:ifc -- /path/to/file.ifc` verifies parser/conversion identities.

## Evidence boundaries

Cost references are optional and require a stated source/date; no production demo unit prices or supplier inquiry service are provided. Structural loads remain presentation assumptions. Compare now defaults to a **source-backed reference model** for supported Sedum roofs: adopted area × published assembly EPD, plus a separate roof-conduction sensitivity scenario using Hong Kong typical weather and explicit assumptions. It shows material quantities, construction emissions and a scope-labelled period range; it does not claim a full-project or whole-building reduction. Open **Compare → 碳排参考模型与依据** to review/change assumptions; **项目数据校正（可选，专业输入）** retains the source-bearing lifecycle/energy input path. Other surfaces/plants are not assigned the roof factor. There is one form. Baseline zero incremental cost/added area does not mean the original building has zero total cost or carbon. Missing values remain unknown, including terrace/ground carbon. Explicit zero needs a source/reason. Changing the model, planting or comparison period requires reconfirming inputs. HTML/JSON retain the before/after comparison, method, sources and missing-data status; full project saving and portable backups retain inputs and sources; changed planting still invalidates their accepted basis. See [CARBON_EVIDENCE.md](CARBON_EVIDENCE.md).

Display mesh areas assume renderer units are metres; area estimates are not professional engineering approval. The carbon comparison covers listed intervention components, excludes plant sequestration and module D, and does not establish whole-building emissions, certified reductions or net-zero status. Future electricity and energy use are not forecast. Structural loading, waterproofing, drainage, facade fixings, access/fire strategy, irrigation and land/utility availability remain unresolved checks.

Scenario profiles are structured rules. Qwen suggestions are conditional drafts; government incentive approval, certification and marketplace transactions are not implemented. Local IFC files are processed in the browser.

### Roof selection and assistant integration

Default planting accepts screened near-flat, pitched and curved roof components with usable upward faces. Roof form and slope remain disclosed engineering checks rather than angle-based exclusions. Planting forms continuous beds along the original faces and openings. See [roof guidance](ROOF_GUIDANCE.md).

Qwen3.7-Plus is configured for **local development** in Inspect and `/api/assistant`. Fill the ignored server-only `.env.local` and restart development to activate your own configuration. Local calls require loopback/same-origin access and bounded process quotas; model responses pass location/species validation and stale-result checks, with local-rule fallback. The public deployment remains disabled until teammate D supplies production authentication and durable rate/spend controls. See [AI handoff](AI_INTEGRATION.md).


### Current Inspect flow

Ask by text or voice → see the real request's waiting state → receive location highlights and plant cards → inspect building locations and adopt recommendations → edit species and coverage in each location card → adopted plants appear with the selected coverage → adjust each card → Finished closes Inspect. Coverage drives both the 3D planted surface and calculation area. These are concept estimates; preview does not require or record review acknowledgement. The viewport no longer has an extra Before/After step. Compare is opened separately.

Adding more locations after preview preserves existing plants and per-location settings. Inspecting a new location and choosing Add to plan adds plants at 50% coverage alongside existing planting. Finished closes Inspect without changing the result. Card order and plant-library targets remain stable across preview. Only the explicit Before control hides the planting preview; cancelling a location removes only that location.

Selected location cards are newest-first: adding/reselecting places a card at the top; changing its species or coverage leaves the order stable. AI failures keep planting unchanged and display a safe reason with HTTP status; local quotas show Retry-After when available.
